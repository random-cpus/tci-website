# TCI Holdings — Web Platform

A recreation of the **TCI Holdings** (`https://tci.company/`) digital experience.

## Features
- **Dynamic Hash Routing (SPA)**: Routing for `#home`, `#about`, `#portfolio`, `#investors`, `#startups`, `#contact`, and company detail views `#companies/:slug` (e.g. `#companies/otc-unlimited`).
- **Luxury Aesthetic**: Cormorant Garamond typography, glassmorphism cards, glowing gradient pills, dark luxury color palette, animated particle canvas background.
- **Interactive Portfolio**: Filterable portfolio grid (FinTech, Gaming & iGaming, Media Tech, SaaS & Enterprise) with dual action buttons (*Learn more* and external *Visit ↗*).
- **Embedded Forms**: Interactive forms for *Register Interest*, *Pitch Submission*, and *Department Inquiries*.
- **Asset Integration**: High-resolution brand logos, office photography, responsive image grids, and official favicon.

## Getting Started
Open `index.html` directly in your browser, or start a local static server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js (npx)
npx serve .
```

Navigate to `http://localhost:3000/` in your browser.
